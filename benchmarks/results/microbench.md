# Stall micro-benchmark

Generated by `python -m benchmarks.microbench` from `benchmarks/data/microbench/stall_a10_d93b769.json`; do not edit by hand.

The engine is driven in-process (no HTTP server, no async loop), so this isolates the scheduling policy; the end-to-end comparison over HTTP is a separate benchmark.

- Scenario: 16 decodes (128-token prompts) each 8 tokens in, then one 3000-token prompt arrives; window = until the long request has 64 tokens and every decode 64 more. Greedy, `ignore_eos`, random prompt ids (seed 0).
- GPU: NVIDIA A10; model Qwen/Qwen3-0.6B in bfloat16, flash attention, block size 256, 662 KV blocks.
- Versions: torch 2.10.0+cu130, flash-attn 2.8.3; commit `d93b769`.
- 3 repeats per configuration after one discarded warm-up each, interleaved; cells are median (min-max) over repeats.
- off = prefill priority (the long prompt runs alone in one step); on-N = mixed batching with an N-token budget per step.
- ITL is over the decodes only, from the gap that spans the arrival onward; p99 is nearest rank over all decodes' gaps.
